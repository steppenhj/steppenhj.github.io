RPi 5 / 8GB

Raspberry Pi 5

PCA9685
Actuator Interface

Motor Driver HAT

Comm I2C Interface Chip PCA9685 Driver TB6612FNG

RPi GPIO 직접 제어 대신 I2C 통신을 사용하여, 전용 칩셋(PCA9685)을 통한 안정적인 하드웨어 PWM 파형을 생성합니다.

Ackermann

Ackermann Chassis

실제 차량과 동일한 조향 기하학(Ackermann Geometry)을 가진 플랫폼입니다. 7.4V Li-Po 배터리로 구동하며 높은 토크를 확보했습니다.

Dual-Power

모터 급가속 시 전압 강하(Voltage Sag)로 인한 RPi 재부팅을 막기 위해 논리 회로와 구동 회로의 전원을 물리적으로 분리했습니다.

Troubleshooting
DECISION

PWM Jitter & Pin Limitation

[Problem] 라즈베리파이의 소프트웨어 PWM은 OS 부하에 따라 신호가 불안정(Jitter)하여 서보모터가 떨리는 현상이 발생했습니다. 또한, 부족한 하드웨어 PWM 핀으로 인해 모터 확장이 제한적이었습니다.

[Solution] GPIO 직접 제어 방식을 포기하고, I2C 기반의 PCA9685 드라이버(HAT)를 도입했습니다. 이를 통해 CPU 부하 없이 안정적인 PWM 파형을 생성하고 정밀한 조향 제어를 구현했습니다.

SOLVED

Control Pipeline Latency

Python(Flask)의 연산 부하가 모터 제어 주기에 영향을 주지 않도록, C++ 기반의 제어 데몬(Daemon)을 분리 설계했습니다. 웹(JS)에서의 조작 명령이 UDP 통신을 통해 지연 없이(Low Latency) 하드웨어(HAL)에 도달하도록 구현하여 반응 속도를 개선했습니다.
