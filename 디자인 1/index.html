Introduction

Bridging Hardware & Intelligence.

안녕하세요, 박해진입니다. 저는 하드웨어의 물리적 제약사항을 소프트웨어로 극복하는 과정에 매력을 느낍니다. 현재는 라즈베리파이와 STM32 기반의 자율주행 RC카 플랫폼 'Neuro-Driver'를 밑바닥부터 구축하며 임베디드 리눅스와 제어 시스템 아키텍처를 깊이 있게 파고들고 있습니다.


단순한 구현을 넘어, "안전하고 신뢰성 있는 시스템 설계"를 지향합니다. Linux와 RTOS 간의 이기종 통신 설계부터, 인지(Perception)와 제어(Control)의 계층 분리를 통해 현대 자동차 산업과 방산 분야에서 요구하는 실전적인 엔지니어링 역량을 쌓아가고 있습니다.

System Integration Roadmap

Neuro-Driver Architecture

Neuro-Driver 플랫폼은 분산 제어(Distributed Control)와 생존형 AI가 결합된 차세대 무인 지상 차량(UGV) 시스템입니다. 총 5단계의 기술적 마일스톤을 통해 완성됩니다.

PHASE 01

Monolithic Control

Raspberry Pi + Web 기반의 초기 프로토타이핑. Linux 환경에서의 하드웨어 제어 한계(OS Jitter)를 분석하고, Watchdog을 통한 Fail-Safe 통신 프로토콜을 구현하여 시스템 안정성을 확보했습니다.

View Architecture
PHASE 02

Distributed Control

STM32 MCU를 도입하여 제어(Real-time)와 연산(Non-RT)을 분리합니다. UART/DMA 비동기 통신과 하드웨어 타이머(Encoder)를 활용하여 정밀한 PID 모터 제어 시스템을 구축합니다.

View Firmware
PHASE 03

Visual Perception

안정된 하부 제어기 위에 Computer Vision을 탑재합니다. Camera Sensor Fusion과 Deep Learning 모델을 활용하여 차선 유지(LKA) 및 장애물 회피 자율주행을 수행합니다.

View Algorithms
PHASE 04

Active Safety & Navigation

Vision 기반의 능동형 Fail-Safe를 구축했습니다. 단순 정지를 넘어, 통신 두절(Heartbeat Loss) 시 Visual Marker를 탐색하고 시작 지점으로 자율 복귀(RTH)하는 생존 알고리즘을 구현했습니다.

View Recovery Logic
PHASE 05

Mission & IFF Logic

생존성이 확보된 플랫폼 위에 피아식별(IFF) 및 전술 기동 알고리즘을 탑재합니다. 적군/아군 인식에 따른 회피, 추적 등 복합 임무(Mission) 수행을 목표로 하는 최종 단계입니다.
