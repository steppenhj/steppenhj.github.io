Fail-Safe Logic

STM32(제어기)는 RPi(서버)로부터 Heartbeat 패킷을 주기적으로 수신합니다. 만약 500ms 이상 패킷이 오지 않으면 즉시 비상 모드(Emergency Mode)로 진입합니다.

  • Level 1: 모터 즉시 정지 (PWM Disable)
  • Level 2: 비상등 점멸 (Visual Alert)
  • Level 3: 3초 후 RTH 시퀀스 시작
stm32_safety.c 
void Safety_Task(void) {
    uint32_t current_time = HAL_GetTick();
    
    // Check Heartbeat Timeout (500ms)
    if (current_time - last_heartbeat > 500) {
        
        // 1. Disengage Manual Control
        Motor_Stop();
        
        // 2. Trigger Return-To-Home
        if (is_safe_to_move()) {
            RTH_Execute_Backtracking();
        }
    }
}

How RTH Works? (Odometry Backtracking)

별도의 GPS 없이도, 엔코더(Encoder)와 IMU 센서를 통해 이동 경로를 메모리에 스택(Stack) 형태로 저장합니다.
비상 상황 발생 시, 저장된 경로의 역순(Reverse Stack)으로 주행하여 시작 지점으로 복귀합니다.
