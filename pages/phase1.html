Python Prototyping

빠른 개발을 위해 Python Flask와 Adafruit CircuitPython 라이브러리를 사용했습니다. I2C 인터페이스로 Motor HAT(PCA9685)에 PWM 명령을 전송하여 DC 모터를 구동했습니다. 

# Python Motor Control Logic
from adafruit_motor import motor
from adafruit_pca9685 import PCA9685

# I2C Bus & PWM Setup
pca = PCA9685(i2c_bus)
pca.frequency = 50

# Direct Control (High Dependency on OS)
def set_motor_speed(throttle):
    pca.channels[0].duty_cycle = throttle

Web-based Manual Control

별도의 조종기 없이 스마트폰이나 PC에서 접속 가능한 웹 컨트롤러를 제작했습니다. WebSockets을 사용하여 HTTP 요청 오버헤드를 줄이고, 조이스틱 입력 데이터를 실시간으로 스트리밍했습니다.

  • Latency: ~40ms (Wi-Fi 5GHz 기준)
  • UI: Virtual Joystick & Gauge

Engineering Insight: The Bottleneck

수동 주행 단계에서는 라즈베리파이만으로 충분했습니다. 하지만 자율주행(Phase 3)을 고려했을 때, 다음과 같은 구조적 한계를 발견했습니다.

⚠️ Anticipated Issues (OS Jitter)

  • Resource Contention: 추후 영상 처리(OpenCV/Deep Learning)가 CPU를 점유할 경우, 모터 제어 프로세스가 후순위로 밀려 제어 주기가 불안정해질 위험이 큼.
  • Non-Realtime OS: 리눅스는 범용 OS이므로 10ms 이하의 정밀한 타이밍 제어(Hard Real-time)를 보장하지 못함.

Solution: "제어 기능을 전용 MCU(STM32)로 이관하여 분산 처리하자."
