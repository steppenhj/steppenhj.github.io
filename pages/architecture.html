SYSTEM BLUEPRINT

Architecture & Design

Neuro-Drive-C++ 시스템의 요구사항, 데이터 흐름, 그리고 하드웨어-소프트웨어 통합 구조를 설계한 다이어그램입니다.
(다이어그램을 클릭하면 원본 크기로 확대됩니다.)

1. System Requirements (Use Case)

시스템의 바운더리와 외부 액터(Operator, Hardware) 간의 상호작용을 정의했습니다.

  • Core Feature: 조이스틱 조작, 엔진 토글, 텔레메트리 모니터링
  • Safety Logic: 통신 두절 시 하드웨어를 강제 통제하는 Execute Fail-safe 설계
  • Control Logic: 조향 시 마찰 저항을 상쇄하는 Cornering Boost 내부 로직 포함

2. Data Flow & IPC (Sequence)

Web Front-end부터 STM32 펌웨어까지 이어지는 이기종 간의 제어 명령 전달 과정을 시간 순으로 설계했습니다.

  • Web → Py: JSON 포맷의 WebSocket 통신
  • Py → C++: struct.pack을 이용한 8-byte 이진 데이터 UDP 송신
  • C++ → STM32: 115200bps UART 기반 ASCII String 시리얼 통신
  • STM32 내부: UART 인터럽트 수신 후 FreeRTOS Message Queue 삽입 및 처리

3. System Structure (Class / BDD)

Raspberry Pi와 STM32, 그리고 하드웨어 액추에이터가 결합된 전체 시스템의 정적 구조(Topology)입니다.

  • Composition: NeuroDrive 최상위 시스템이 각 하위 모듈을 소유(has-a)하는 토폴로지 구성
  • High-Level: 통신망(WebSocket, UDP)과 상위 제어(Linux) 명시
  • Low-Level: 실시간 제어(FreeRTOS) 및 하드웨어 통신 인터페이스(UART) 분리 설계
  • Power & Actuator: 구동을 위한 전압(7.4V) 조향 및 구동 액추에이터 명세 포함
