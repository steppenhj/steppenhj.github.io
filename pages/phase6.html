The Arbitrator: Human-in-the-loop

자율주행 시스템은 완벽하지 않으므로 언제나 사람의 개입을 최우선으로 합니다. 소프트웨어적인 중재자(Arbitrator) 패턴을 구현하여 제어권 충돌을 방지합니다. 

// Safety Override Logic (Concept)
void Arbitrate_Control_Signal() {
    if (user_joystick.is_active()) {
        // 1. Human Input Detected -> Disengage AI
        current_state = MANUAL_MODE;
        stm32.send(user_joystick.data);
    } 
    else {
        // 2. No User Input -> AI Auto Pilot
        current_state = AUTO_MODE;
        stm32.send(ai_lane_follower.data);
    }
}
