Layer 1: The Gateway

웹에서의 비동기 요청을 받아 안전장치(Safety Lock)를 거친 후, C++ 코어가 이해할 수 있는 Binary Packet으로 압축하여 전송합니다.

# float(4byte) 2개를 8byte 패킷으로 압축

Layer 2: The Core

Multi-threading 구조입니다. 수신(Receiver) 스레드와 제어(Control) 스레드가 Mutex를 통해 데이터를 안전하게 공유하며 하드웨어(UART)로 명령을 쏘아줍니다.

control_core.cpp
// Thread 1: Receiver (Locking)
lock_guard<mutex> lock(data_lock);
shared_data = packet;

// Thread 2: Controller (Non-blocking Write)
snprintf(buf, ... "%d,%d\n", speed, angle);
write(serial_fd, buf, len);

Layer 3: RTOS & Queue (STM32)

인터럽트 처리를 최소화하고, 시스템 안정성을 확보하기 위해 3-Task Architecture를 설계했습니다.

  • Comm Task (Producer): UART 인터럽트로 데이터를 받아 Queue에 적재 (Non-blocking).
  • Motor Task (Consumer): Queue에서 목표 속도를 꺼내고, 엔코더 피드백과 비교하여 P-제어(kp=0.5)로 PWM 보정. (Closed-Loop, 100Hz)
  • Safety Task: 500ms 이상 통신이 끊기면 Hardware Stop 강제 수행.
main.c (FreeRTOS Tasks)
// 1. [Producer] UART Callback
void HAL_UART_RxCpltCallback(...) {
  // 큐에 넣고 즉시 복귀 (ISR 최소화)
  osMessageQueuePut(cmdQueue, &msg, 0, 0);
}

// 2. [Consumer] Motor Task (100Hz PID)
void StartTask02(...) {
  PID_t pid = { .kp=0.5, .ki=0, .kd=0 };
  while(1) {
    osMessageQueueGet(cmdQueue, &rcv, ...);
    target_speed = rcv.speed;
    error = target_speed - encoder_rpm;
    output = PID_Calculate(&pid, error);
    __HAL_TIM_SET_COMPARE(&htim2, ..., output);
  }
}

2-DOF Control: Feedback + Feedforward

단일 PID만으로는 코너링 시 토크 부족 문제를 해결할 수 없었습니다.
STM32의 Feedback(외란 보상)과 Python의 Feedforward(선제 보상)를 결합한 2-DOF 구조로 해결했습니다.

Feedback (STM32)

P-only 속도 제어 (kp=0.5, 100Hz)
엔코더 피드백으로 외란(부하, 경사)에 의한 속도 오차를 실시간 보정. TIM1 하드웨어 카운터로 CPU 부하 Zero 속도 측정.

Feedforward (Python)

Cornering Boost (조향 비례 출력 증폭)
조향 시 마찰 증가를 사전 보상. 조향각 50% 이상에서 최대 3배 부스트 + 최소 토크 40% 강제 주입.

왜 2-DOF인가? — Feedback은 "이미 발생한 오차"를 보정하고, Feedforward는 "예측 가능한 오차"를 선제 보상합니다. 두 제어가 독립적으로 동작하며 합산되어, 단일 PID보다 빠른 응답과 안정적인 코너링을 달성합니다.

Performance Verification

RTOS와 인터럽트 큐(Queue)를 도입하여 구조 복잡도는 증가했지만, 결과적으로 "예측 가능한 제어(Deterministic Control)"를 달성했습니다.

Test Scenario:

Host(노트북)에서 고속으로 랜덤한 주행 명령을 쏟아붓는 상황(Stress Test)에서도, STM32가 100Hz 주기를 놓치지 않고 즉각 반응하는 것을 확인했습니다.
