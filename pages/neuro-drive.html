Main Project

Neuro-Drive
Control System

Raspberry Pi 5와 STM32F411RE를 기반으로 한 분산 제어 RC카 시스템.
Brain(리눅스) & Reflex(MCU) 아키텍처로 고수준 판단과 실시간 제어를 분리하고,
FreeRTOS 기반 100Hz PID 루프, RTH 안전 복귀, OTA 펌웨어 업데이트를 구현했습니다.

C++ Python FreeRTOS STM32 HAL UART WebSocket PID Control OTA MBSE

PHASE 01

Monolithic Linux Control

Raspberry Pi Python-C++ IPC I2C
PHASE 02

STM32 분산 아키텍처

MCU를 도입하고 UART 통신으로 제어 부하를 분산. Brain & Reflex 구조의 시작

STM32F411RE UART Distributed
TURNING POINT

In-Operation Failure & Pivot

운행 중 실시간 제어 실패 발생. Bare-metal의 한계를 인식하고 RTOS 전환을 결정한 전환점

Critical Failure Architecture Pivot
PHASE 03

RTOS & ISR 도입

FreeRTOS 기반 선점형 멀티태스킹 도입. 100Hz PID 제어 루프, DMA, Interrupt-Driven 아키텍처

FreeRTOS PID 100Hz ISR DMA
PHASE 04

RTH Safety System

엔코더 기반 경로 기록 및 PID 역추적 복귀 알고리즘. Watchdog + Keep-alive 안전 메커니즘

Return-to-Home Encoder Path Watchdog
PHASE 05

OTA Firmware Update

UART 기반 커스텀 부트로더 설계. Sector 단위 Flash 관리, CRC 검증, 핸드셰이크 프로토콜

Bootloader IAP CRC Verify
