Server Architecture Log #01

Async Eventlet & Semaphore Locking

Flask-SocketIO의 비동기 환경에서 단일 시리얼 포트(`/dev/ttyACM0`)에 대한 Race Condition을 방지하기 위해 락(Lock) 메커니즘을 적용했습니다.

  • Library: eventlet.semaphore.Semaphore(1)
  • Implementation:
    send_to_stm32() 함수 진입 시 Context Manager(with lock)을 사용하여 Thread-safe한 시리얼 쓰기(Write) 보장.
  • Outcome: 동시 접속 제어 시 발생하던 시리얼 리소스 충돌 및 패킷 깨짐 현상 완벽 해결.
Safety Logic Log #02

S/W Watchdog & Timeout

통신 두절 시 차량이 폭주하는 것을 막기 위해 펌웨어 레벨에서 Time-based Watchdog 로직을 구현했습니다.

  • Logic:
    if (HAL_GetTick() - last_command_time > 500)
  • Action:
    TIM2 채널의 PWM Compare 값을 0으로 강제 설정하여 모터 즉시 정지.
  • Verification: RPi 전원 차단 테스트 시 0.5초 내 구동축 Lock 확인.
Troubleshooting Log #03

Pin Muxing & Hardware Isolation

초기 개발 시 PWM 신호가 출력되지 않는 문제 발생. 단위 테스트(Isolation)를 통해 HAL 생성 코드의 결함을 발견하고 수정했습니다.

  • Analysis: 레지스터 상 Timer Counter는 동작하나 GPIO Output이 0V 유지.
  • Root Cause: GPIO_AF(Alternate Function) 설정 누락.
  • Solution:
    Force_Hardware_Config() 함수를 작성하여 GPIO_AF1_TIM2 매핑을 명시적으로 재설정.
Communication Log #04

UART Circular DMA & Ring Buffer

CPU가 1바이트씩 수신하는 Polling 방식의 오버헤드를 제거하기 위해 DMA(Direct Memory Access)를 도입했습니다.

  • Architecture: UART Rx → DMA Circular Mode → Memory Buffer
  • Benefit:
    CPU 개입 없이 백그라운드에서 데이터 수신. Half/Full Complete Interrupt를 통해 주기적으로 데이터 파싱.
  • Result: 고속 주행 중에도 제어 루프 주기(10ms) 안정성 확보.
Sensor Fusion Log #05

Hardware Quadrature Decoding

S/W 인터럽트 방식 대신 STM32의 타이머 하드웨어 기능을 활용하여 CPU 부하 없이 엔코더 펄스를 카운팅합니다.

  • Config: TIM1 in TIM_ENCODERMODE_TI12 (x4 resolution)
  • Algorithm:
    delta = (int16_t)(cnt - prev_cnt)
    Overflow(65535)를 2의 보수법으로 자연스럽게 처리하여 속도 계산.
