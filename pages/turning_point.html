Incident Report: The 7.4V Disaster

상황: 자율주행 알고리즘 테스트 중 차량이 벽과 충돌.
원인: 충격으로 헐거워진 배터리 커넥터가 이탈하며 7.4V 전원선이 RPi 3.3V GPIO를 타격.
결과: 과전압으로 인한 고장. Main Controller(Brain) 손실.

REALIZATION: "실제 주행은 통제된 환경과 다르다. 충돌 직전 0.1초라도 더 빨리 판단하고 멈췄어야 했다.
솔직한 마음으로 너무 성급한 자율주행 학습이었다. 수동주행을 더욱 완벽하게 해보자"

Why Migration? (Safety First)

Problem: GIL & Non-determinism

Python(Flask)이 Vision 연산을 처리하는 동안 GIL(Global Interpreter Lock)과 GC pause로 인해 제어 명령의 처리 타이밍이 비결정적(non-deterministic)으로 변하는 구조적 문제가 존재했습니다.

Solution: Process Isolation

제어/안전 로직을 독립 C++ 프로세스로 분리.
Python의 GIL/GC와 무관하게 자체 이벤트 루프에서 동작하므로, 카메라 연산 부하와 상관없이 워치독과 제어 명령을 결정적 타이밍으로 처리합니다.

control_core.cpp (Fail-safe Logic)
// Python의 간섭 없이 독립적으로 루프 실행
while (true) {
  // 1. Watchdog: 통신 두절 시 즉시 정지
  if (check_timeout() > 50) { // 50ms Timeout
    emergency_stop();
    continue;
  }

  // 2. High-speed Control Calculation
  process_control_loop();
}
