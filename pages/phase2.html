Troubleshooting: Pin Muxing Fix

HAL 라이브러리 초기화 문제로 모터 PWM 신호가 출력되지 않는 현상을 발견했습니다. 레지스터 설정을 강제하는 함수를 작성하여 해결했습니다. 

static void Force_Hardware_Config(void) {
  GPIO_InitTypeDef GPIO_InitStruct = {0};
  __HAL_RCC_GPIOA_CLK_ENABLE();
  
  // Force Connect TIM2 to PA0
  GPIO_InitStruct.Pin = GPIO_PIN_0;
  GPIO_InitStruct.Mode = GPIO_MODE_AF_PP;
  GPIO_InitStruct.Alternate = GPIO_AF1_TIM2;
  HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
}

Result

이 조치를 통해 PWM 주파수 1kHz가 오실로스코프상에서 안정적으로 관측되었으며, 응답 속도가 기존 500ms(Python only)에서 10ms(Distributed)로 획기적으로 개선되었습니다.
